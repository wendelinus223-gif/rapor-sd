Panduan Penggunaan Aplikasi

Petunjuk langkah demi langkah untuk mengoperasikan sistem Rapor SD Multi-Sekolah.

1. Akses & Multi-Sekolah

  • Daftar Sekolah Baru: Klik "+ Daftarkan Sekolah Baru" di modal login, masukkan NPSN unik, Nama Sekolah, dan Password.
  • Login System: Masukkan NPSN dan Password terdaftar untuk masuk ke database sekolah Anda.
  • Isolasi Data: Setiap sekolah yang terdaftar via NPSN memiliki ruang penyimpanan terpisah yang aman di peramban (localStorage).

2. Dashboard & Monitoring

  • Ringkasan Utama: Memantau total siswa terdaftar, NPSN sekolah aktif, serta Tahun Ajaran dan Semester.
  • Distribusi Predikat: Melihat persentase pencapaian nilai (Predikat A, B, C, D, E) seluruh siswa secara visual.
  • Status Kelengkapan: Indikator progress bar untuk memastikan berapa banyak siswa yang nilai rapornya sudah terisi 100%.

3. Kelola Data Peserta Didik

  • Input Manual: Gunakan tombol "+ Tambah Siswa" atau tombol Edit untuk memperbarui biodata lengkap.
  • Impor/Ekspor CSV: Unduh format CSV, isi data secara massal di Excel, lalu unggah kembali via tombol Impor Biodata CSV.
  • Peringkat Kelas: Peringkat akademis dihitung otomatis berdasarkan akumulasi perolehan total nilai.

4. Input Nilai & Cetak Rapor

  • Otomatisasi Deskripsi: Predikat dan Deskripsi Capaian Kompetensi langsung terbentuk otomatis saat nilai (0-100) diisikan.
  • Penyesuaian IPAS: Mapel IPAS otomatis disesuaikan (hanya tampil pada Kelas III, IV, V, dan VI).
  • Cetak Standar F4: Klik Cetak Rapor (F4 Berkelanjutan) untuk hasil cetak presisi pada kertas ukuran Folio/F4 (215 x 330 mm).

5. Transisi Tahun Ajaran & Kenaikan Kelas Masal

  • Promosi Otomatis 1-Klik: Buka menu Pulihkan/Backup Data dan klik "Jalankan Proses Kenaikan Kelas Masal" untuk memproses pergantian tahun ajaran baru secara otomatis.
  • Auto-Backup Riwayat: Sebelum mutasi data berjalan, sistem mengunduh cadangan file JSON secara otomatis agar data tahun ajaran sebelumnya tersimpan aman.
  • Perubahan Tingkat Kelas: Siswa Kelas I s.d. V otomatis naik ke tingkat berikutnya (I→II, II→III, dst.). Siswa Kelas VI otomatis dinyatakan Lulus dan diarsipkan dari daftar siswa aktif.
  • Pembaruan Sistem: Format Tahun Ajaran otomatis bertambah (misal 2026/2027 → 2027/2028), semester diatur ke Semester 1 (Ganjil), dan database nilai di-reset agar bersih untuk penginputan nilai baru.

6. Pemeliharaan & Cadangan Data (Backup)

Sistem menyimpan seluruh data di memori peramban (localStorage). Untuk menghindari kehilangan data saat peramban dibersihkan, pastikan Anda secara berkala melakukan Download Backup JSON pada menu Backup & Restore Data.
